# 月读竞技场

按照新版开发文档重建的浏览器端 3v3 类 MOBA 竞技场原型。

## 核心玩法

- 蓝方“月辉队” vs 红方“星蚀队”
- 玩家控制蓝方一名英雄，双方各 2 名 AI 英雄
- 小兵每波自动从基地出发并沿中路线推进
- 双方拥有防御塔与基地核心
- 地图上下方有资源点，可占领获得分数与临时增益
- 默认 MOBA 操作：右键移动，A/左键普攻，Q/W/E/R 技能
- 英雄死亡后 5 秒复活
- 摧毁敌方核心，或倒计时结束后分数更高的一方获胜

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | 鼠标右键 |
| 普攻 | A / 鼠标左键 |
| 技能 | Q / W / E / R |
| 镜头回到自己 | Space |
| 计分面板 | Tab |
| 暂停 | Esc |

移动端显示虚拟摇杆与技能按钮。
